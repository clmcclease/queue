# Contributing

Thanks for your interest. Queue is an early, personal project, so:

- **Issues are welcome:** bugs, ideas, and sites that don't work. Please include your OS, the
  link if you can share it, and the error the row shows.
- **Open an issue before a pull request,** so we can agree on the change first. Unrequested
  pull requests may be closed.
- Contributions are accepted under the project's license (MIT OR Apache-2.0).

How the project is run: `AGENTS.md`, `docs/STATUS.md` and `docs/DECISIONS.md`.
